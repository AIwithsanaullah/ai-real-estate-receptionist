## 🔄 How It Works

```
1. Lead sends WhatsApp message
        ↓
2. AI qualifies lead (budget, timeline, property type)
        ↓
3. RAG system answers property-specific questions
        ↓
4. High-intent lead → Books viewing via Google Calendar
        ↓
5. Confirmation sent to lead + agent notified
        ↓
6. Follow-up sequence triggered automatically
```
